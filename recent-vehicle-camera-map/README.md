# 关联车辆近期卡口地图

本目录是 GitHub Pages 静态部署包：坐标已在本地转换为 WGS84，页面由 Mapbox GL JS 渲染。页面支持在“沪/浙ES0933”和“沪FD1658”两辆车之间多选，并按日期区间筛选卡口、统计、热力图和按车辆/日期分段的卡口时序线；默认勾选两辆车并展示全部时间范围。两辆车的卡口与时序线使用独立颜色显示。

嘉行公路2605号（宝钱公路—嘉行公路路口北侧稍偏西）、励学路1111号、丰兆路122号以静态红旗标记为重点常去点位。丰兆路红旗仍显示“122号”，底层坐标改用更稳定可编码的丰兆路118号高置信门牌结果。Mapbox 公共令牌在 GitHub Pages 构建阶段注入；访问页面时不会调用百度 API 或天地图 API，也不会在前端暴露这两类服务密钥。

页面包含“沪FD1658 · 指定日期轨迹演示”：读取《沪FD1658车辆新增轨迹(1).xls》的日期、起点、终点和经停顺序，并与三份 1658 卡口 CSV 的 3618 条有效记录融合（新增 `1658.csv` 的 1 条与原末条重复，已去重）。首次打开只展示日期和文字说明，不绘制任何轨迹；点击播放后，页面才用最多 25 个时空锚点临时请求 Mapbox Directions 道路路线。功能支持播放、暂停、拖动进度、清除和再次播放；Mapbox 路线请求失败时自动退回卡口折线。XLS 标注熄火且卡口无记录的日期会禁用播放。

停留时间不是 GPS 精确停车时间：仅对 15 分钟以上、相邻卡口距离不超过 3 公里的空窗，用“卡口时间差减去按 30km/h 估算的最短驶入/驶出时间”给出约数，并在页面中标为“疑似停留/卡口空窗”。跨区监控缺失或同一空窗包含多个 XLS 点位时，只能解释为活动时间上限，不应作为精确到访结论。

轨迹静态数据由 `build_trajectory_data.py` 生成到 `trajectory_data.js`。首次或需要更新 XLS 点位坐标时，在 1Password Chem_Map 环境已挂载为上级目录 `.chemmap.env` 的前提下运行：

```bash
/usr/bin/python3 build_trajectory_data.py --refresh-geocodes
```
