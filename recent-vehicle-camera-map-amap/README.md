# 关联车辆近期卡口地图（高德对比版）

这是现有 Mapbox 地图的独立高德 JS API 2.0 对比页，保留两车复选、日期区间、高频点位、搜索、热力图、按日时序线、街道/卫星切换和三个重点常去点位。卡口按车辆分别进行数字聚合，随地图缩放自动聚合或拆分；街道与卫星底图通过显隐切换，避免重置卡口覆盖物。

嘉行公路2605号重点点位按已确认位置标在宝钱公路—嘉行公路路口北侧稍偏西。点位在发布前由静态 WGS84 坐标离线换算为 GCJ-02。网页访问时只加载高德地图服务，不调用天地图、百度或 Mapbox。高德 JS Key 与安全密钥由 GitHub Actions Secrets 在 Pages 构建阶段注入，不写入仓库源码。
